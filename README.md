# LoLQuizJava 🎮

A Java-based quiz application inspired by League of Legends, the multiplayer online battle arena game developed by Riot Games.

LoLQuizJava challenges players with questions related to League of Legends, allowing them to test their knowledge of the game's champions, abilities, lore, and gameplay. The project demonstrates fundamental Java programming concepts through an interactive quiz experience.

## Features

- League of Legends Trivia: Answer questions about the game.
- Multiple-Choice Questions: Select from available answers, if supported by the implementation.
- Score Tracking: Keep track of correct answers and overall performance.
- Interactive CLI: Play directly through the terminal or command prompt.
- Java Fundamentals: Demonstrates variables, conditional statements, loops, and user input.
- Educational Project: Provides practical experience in Java application development.

## Requirements

- Java Development Kit (JDK)
- Terminal or command prompt
- `LoLQuizJava.java`

## Usage

### 1. Clone the Repository

```bash
git clone <repository-url>
cd LoLQuizJava
```

Replace `<repository-url>` with your repository's Git URL.

### 2. Compile the Program

```bash
javac LoLQuizJava.java
```

### 3. Run the Program

```bash
java LoLQuizJava
```

Follow the on-screen instructions to answer the quiz questions and view your results.
